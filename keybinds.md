## 🪟 Window & Workspace Management

* SUPER + W: Kills the active window.
* SUPER + F: Toggles floating or tiled status for the current window.
* SUPER + H: Toggles pseudo-tiling (dwindle layout).
* ALT + F: Toggles fullscreen mode.
* SUPER + CTRL + F: Toggles between global floating and global tiling modes via a script.
* SUPER + Arrow Keys: Moves window focus (Left/Right/Up/Down).
* SUPER + SHIFT + Arrow Keys: Moves the current window within the workspace.
* SUPER + [0-9] / SUPER + CTRL + [0-9]: Switches to workspaces 1–10 and 11–20 respectively.
* SUPER + SHIFT + [0-9] / SUPER + SHIFT + CTRL + [0-9]: Moves the active window to workspaces 1–10 and 11–20 respectively.
* SUPER + Mouse Scroll: Scrolls through existing workspaces.
* SUPER + LMB / RMB (Drag): Moves and resizes windows using the mouse.

## 📜 Scrolling Layout Controls

* SUPER + / or ,: Moves focus right or left across columns.
* CTRL + ALT + / or ,: Alternate shortcut for column focus.
* CTRL + ALT + D or A: One-handed shortcuts to focus columns right or left.
* SUPER + SHIFT + / or ,: Swaps current column position right or left.
* CTRL + ALT + SHIFT + D or A: One-handed shortcuts to swap columns right or left.
* SUPER + = or -: Adjusts current column width granularly.
* SUPER + SHIFT + = or -: Cycles through preset widths forward and backward.
* SUPER + ] or [: Performs granular layout movement (+/- 200).
* SUPER + ' or SUPER + SHIFT + F: Resizes column to default layout size.
* SUPER + SHIFT + ': Promotes the focused window into a new column.
* SUPER + G: Toggles center vs. fit layout.
* SUPER + SHIFT + CTRL + F: Toggles scrolling follow focus via a script.

## 💻 System & Menus

* SUPER + M: Triggers a Rofi prompt to quit Hyprland.
* SUPER + SHIFT + M: Triggers a Rofi prompt to shut down the system.
* SUPER + SHIFT + CTRL + M: Triggers a Rofi prompt to reboot the system.
* SUPER + L: Locks the screen using hyprlock.
* SUPER + SHIFT + R: Reloads the Hyprland configuration and triggers a notification.
* ALT + SPACE: Toggles the Rofi application menu.
* SUPER + SPACE: Opens the Rofi calculator (rofi -show calc).
* SUPER + TAB: Opens the Rofi window switcher.
* ALT + TAB / ALT + SHIFT + TAB: Cycle windows using snappy-switcher.
* SUPER + . (Grave): Opens the Rofi emoji picker.
* SUPER + CTRL + T: Toggles the trackpad via script.
* SUPER + CTRL + D: Launches your dock script.
* SUPER + N: Dismisses active desktop notifications.

## 📸 Screenshots & OCR

* ALT + SHIFT + S: Takes an area snip using grimblast (with freeze safety and automated unfreeze).
* CTRL + Print: Captures the active window.
* SHIFT + Print: Captures all monitors.
* ALT + Print / Print: Captures the current monitor only.
* CTRL + ALT + Delete: Emergency shortcut to force kill stuck screenshot/picker instances (hyprpicker, slurp, still).
* SUPER + SHIFT + T: Triggers OCR4Linux restricted to English text.
* SUPER + SHIFT + E: Triggers OCR4Linux with interactive full selection.

## 🎵 Hardware, Media & Environment

* XF86 Volume & Mute Keys: Handles system audio volume and mic muting using wpctl.
* XF86 Brightness Keys: Controls local screen brightness via brightnessctl.
* ALT + Up / Down: Adjusts external monitor brightness via ddcutil on bus 4.
* XF86 Media Keys / ALT + Q: Toggles media play/pause.
* ALT + R: Skips to the next media track.
* ALT + W: Rewinds to the previous media track.
* ALT + SHIFT + B: Toggles wallpaper via matuwall.
